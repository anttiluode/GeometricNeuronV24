Gate 3A / state write

Perturb to reveal, do not modify

x(t+1)=Gθ x(t)
write: x ← x + w
θ unchanged

An equal-energy uniform write remains an exact null. A localized write excites spatial structure, so hidden transport direction changes later addressed pulses.

Gate 3B / operator write

Modify, erase, then diagnose

θ ← θ + Δθ(address)
x ← 0
x ← public diagnostic load
later y = hᵀx

The persistent write lives in the operator map. Erasing the fast field does not erase it. Reload the common diagnostic field and later pulses still depend on where the operator changed.

The browser is a mechanism sketch. The locked Python gate is the receipt: 3A active 1.000 vs random 0.355; 3B noise-aware 1.000 vs raw variance 0.367 and random 0.480; both halves pass 10/10 robustness seeds.

Neuron boundary. A diagnostic state write can be compared to targeted dendritic stimulation; a persistent operator write can be compared to lasting local synaptic/channel/geometry change.
